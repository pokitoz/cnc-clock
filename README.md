## CNC3010

### Pitfalls

- Accurate wood dimension in Fusion360 (see Posage Brut)
- Accurate drill size
- Make sure to select the origin
- Make sure to properly block the support

Use "Conception" and then "Fabrication" in Fusion360
Need "Posage" defining the position
Select "Poche 2D", select the faces to be drilled in and in "Passes" use "Profondeur Multiple".
